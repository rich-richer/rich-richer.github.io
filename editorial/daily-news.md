# 双语每日新闻（daily-news）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：工作日。窗口：过去约 24 小时。
- 读者：AIggy。分析师语气，不做标题党。
- 使用 AIHOT：是（24 小时精选）。

## 范围

三个板块，写进 `category`：

| category | 内容 |
| --- | --- |
| `AI科技` | AI 模型、产品、基础设施、研究进展；链上基础设施、区块链与 AI 的交叉 |
| `市场商业` | 宏观、公司、资本市场、监管；经核实的重要区块链 / 加密事件（监管、ETF、机构资金、合规产品） |
| `科学` | 重要科研成果与期刊发表 |

- 每个板块 3–6 条，**仅在确有真实新闻时才写**。板块无可靠更新就不写该板块，并在报告中说明。
- 区块链 / 加密不单设板块，不写单纯的价格涨跌闲谈。
- 检索优先 X、YouTube、官方博客；中国平台内容仅在能独立核实时采用。

## 线索源

```text
GET https://aihot.news/api/v1/items?mode=selected&window=24h&limit=30
```

AIHOT 只作线索，入选条目必须打开 `links.original` 核实（规则见 README 第 5 节）。

## 版面映射

- **Today's takeaways**：选出当天最重要的 1 条做 `lead`、其次 2 条做 `important`，可跨板块。
- 其余条目为 `normal`，按板块顺序排列：AI科技 → 市场商业 → 科学。
- 双语：英文来源必须填 `originalTitle`；头条尽量附 2 个以上来源，让原标题在来源面板中显示（规则见 README 第 4 节）。
- 每条的 `brief` 用中文写清「发生了什么」；头条和重要条目在 `brief` 后半句点出「意义」，整句不超过 80 字。
- 专业术语首次出现写作「中文（English）」。
