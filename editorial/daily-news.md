# 双语每日新闻（daily-news）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：周一、周四（试行出刊表）。窗口：**自上一期以来**（约 3–4 天，`coverage.start` = 上一期的 `coverage.end`，见 README 第 3 节）；首期取过去 24 小时。
- 读者：AIggy。分析师语气，不做标题党。
- 使用 AIHOT：是（7 天精选，按 `publishedAt` 只取窗口内的）。

## 范围

本刊是**完整新闻主刊**（2026-09-27 改版；2026-09-30 起并入原工作日早晨简报的 AI 工具、YouTube 创作者、今日提醒，数字货币与区块链移到金融与加密简报）。六个板块，写进 `category`：

| category | 内容 | 条数 |
| --- | --- | --- |
| `AI科技` | AI 模型、产品、基础设施、研究进展；**重点跟进 Claude、ChatGPT、Gemini 等主流 AI 工具的更新**（新模型、新功能、价格、下线、重大事故），工具类条目在正文末尾加一句「怎么用 / 要注意什么」 | 3–6 |
| `AI安全观察` | 重要漏洞、提示词注入（prompt injection）、越狱（jailbreak）研究和防护进展；按 README 第 5 节第 5 条写法，标明证据等级（研究演示 / 已确认漏洞 / 已发现实际利用）和修复状态 | 每期 1–2 |
| `市场商业` | 宏观、公司、资本市场、监管 | 3–6 |
| `创作者平台` | YouTube 等创作者平台的算法与推荐变化、新功能、分成与变现政策、重大频道 / 创作者动态 | 0–2 |
| `科学` | 重要科研成果与期刊发表 | 3–6 |
| `近期提醒` | 下一期出刊前需要留意或行动的非金融事项：产品与服务下线、政策生效日、报名截止等，写清日期（北京时间）和出处（金融数据与议息会议归金融与加密简报的「财经日历」） | 0–2 |

- 窗口跨 3–4 天，按「窗口内最重要」挑选，不按天平均；同一事件在窗口内有新进展时合并成一条，写清最新进展和时间。
- 每个板块**仅在确有真实新闻时才写**。板块无可靠更新就不写该板块，并在报告中说明；`AI安全观察` 在窗口内确无可信新动态时，同样不凑数，在报告中写明。
- `市场商业` 写宏观、公司、产业、贸易与监管。金融市场行情、央行与利率、数字货币与区块链由金融与加密简报完整报道，本刊只在影响特别大时写短摘要并链接过去。
- `创作者平台` 与自媒体选题简报分工：本刊写平台规则与政策的事实，选题简报写可做的话题与切入角度，两刊不重复完整报道。
- `AI安全观察` 只写短讯：AI 安全公开动态已刊登完整技术分析的事件，改为短摘要并链接过去；本刊先报道的，AI 安全刊之后写完整分析时会链接回来。
- 论文类新闻只报道特别重要的，其余归 AI 研发前沿周报。
- 检索优先官方博客、X、YouTube 与路透社、彭博、美联社等可信媒体，优先当天和前一天的头条；中国平台内容仅在能独立核实时采用。多跑几轮检索，确保每条都有明确日期。

## 线索源

```text
GET https://aihot.news/api/v1/items?mode=selected&window=7d&limit=50
```

AIHOT 只作线索，入选条目必须打开 `links.original` 核实（规则见 README 第 5 节）。

## 版面映射

- **Today's takeaways**：选出当天最重要的 1 条做 `lead`、其次 2 条做 `important`，可跨板块。
- 其余条目为 `normal`，按板块顺序排列：AI科技 → AI安全观察 → 市场商业 → 创作者平台 → 科学 → 近期提醒。
- **每条都中英对照**（沿用原「Daily news briefing」任务的写法）：`summary` 先写中文一到两句，再另起「EN:」写对应的英文一到两句。英文是对同一事实的专业表述，不是逐字翻译。英文来源另填 `originalTitle`；头条尽量附 2 个以上来源，让原标题在来源面板中显示（规则见 README 第 4 节）。
  - 页面会把「EN:」之后的英文段拆出来，在每条中文下方单独显示一行（头条最多 4 行，其余最多 3 行；见 `docs/LOCAL_CHANGES.md`）。
  - 长度：`summary` 总长仍不超过 400 字（英文字母和空格也计入）。中文段控制在约 230 字以内，英文段一句、约 150 字符以内。
  - 头条的中文段仍要把「意义」放在前 80 字内。
- 每条的 `brief` 用中文写清「发生了什么」；头条和重要条目在 `brief` 后半句点出「意义」，整句不超过 80 字。
- 专业术语首次出现写作「中文（English）」。
