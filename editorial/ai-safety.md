# AI 安全公开动态（ai-safety）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：每周三。窗口：过去 7 天。
- 主题：**公开的** AI 安全与滥用防范新闻。分析师语气。
- 使用 AIHOT：否。

## 关键范围限制（硬性）

只写高层次的公开披露：厂商的风险预备框架（preparedness frameworks）、政策、防御性工具发布、负责任披露（responsible disclosure）类新闻。

**不得**包含越狱配方、漏洞利用步骤、绕过方法、能击穿安全防护的提示词，或来自越狱社区的操作教程。若某条新闻只关于某种越狱技术，要么不写，要么压缩成一句「厂商已披露存在某类滥用风险」，不写方法。

## 条目安排

- 共 3–8 条符合范围的条目，不凑数。`category`：`政策监管` / `厂商框架` / `防御工具` / `披露与事件`。
- 摘要并入头条：`lead` 的 `summary` 开头用一两句话概括本周全局。
- `important` 2 条。
- 英文来源填 `originalTitle`，头条尽量附 2 个以上来源，让原标题在来源面板中显示（规则见 README 第 4 节）。
