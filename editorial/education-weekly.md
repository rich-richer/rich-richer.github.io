# 升学就业周报（education-weekly）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：每周六。窗口：过去 7 天，外加仍在有效期内的截止日期。
- 读者：**面向高中生家庭的通用版本**，只看中国国内。务实，不写灰色地带或违法的绕道方法。
- 使用 AIHOT：否。

## 隐私（硬性）

本刊公开发布。**不写**任何家庭信息：孩子的年级、所在城市或省份偏好、具体目标院校、家庭情况。一律写成面向「高中生家庭」的通用分析；需要区分年级时用「高一 / 高二 / 高三家庭」泛指。

## 事实标准

- 深度参照：热度 ≠ 就业质量；引用教育部、麦可思、新华社这一级别的来源。
- 仅见于媒体的数字用「⚠️（媒体转述）」标出。
- **绝不编造**招生计划、分数线、名额、保送名单或薪资。

## 政策通道（每周全部排查）

1. 普通高考统招（批次、计划、选科要求信号）
2. 强基计划
3. 综合评价招生
4. 高校专项 / 地方专项 / 其他专项（户籍学籍条件）
5. 保送生（外语类、奥赛国家集训队等现行公开规则）
6. 学科竞赛路径（数理化生信）：多数已不再是高考「加分」，而是强基 / 综评 / 校测 / 营的资格，写清现行口径
7. 高水平运动队 / 体育类招生
8. 艺术类及相关校考政策（仅公开政策有变化时）
9. 提前批（军校、公安、公费师范、小语种等）
10. 港澳高校内地招生
11. 中外合作办学 / 试点班
12. 其他公开照顾或专项政策（仅有重大政策变动时）

只对**有新消息**或**仍有有效截止日期**的通道出条目。排查结果「本周无可靠更新」的通道不出条目，但要在头条 `summary` 里用一句人话总结，例如「本周通道一句话：……」。

## 条目安排

| category | 内容 |
| --- | --- |
| `政策通道` | 有新消息的通道，每条：事实来源 → 走势判断（标明是判断）→ 对高中生家庭的含义 |
| `院校与专业` | 院校与专业走势；给出 12–24 个月情景（基准 / 偏热 / 偏冷）和证伪信号 |
| `就业与选专业` | 面向高中阶段的方向判断，不做假志愿表 |
| `定向与就业接收` | 毕业后用人单位接收或定向就业更明确的路径：定向培养、选调生、军校 / 公安院校、委培、试点班对接等。每条：事实（招生简章 / 部委 / 学校官网）→ 接收机制 → 约束（服务年限 / 违约 / 户籍）→ 含义。绝不编造「包分配」，区分「媒体宣传」与「官方文件」 |

- `lead`：本周最重要的变化。`summary` 开头写「本周通道一句话」，结尾附「家长本周行动清单」（不超过 3 项）。
- `important` 2 条。
- 做判断时必须用：判断 → 依据（事实 / 机构观点）→ 置信度（高 / 中 / 低）→ 证伪信号，写成可读的中文句子。
- 「对高中生家庭的含义」写进 `brief` 后半句，必须具体、直白：这周该做什么、不该做什么。禁止空泛的「需关注」「建议留意」。

## 写作质量

读者是在手机上用中文阅读的忙碌家长：

1. 中文优先，先说结论，再给证据和链接。
2. 一段一个意思，像心平气和地给朋友讲清楚；不是公文腔，也不是先写英文再翻成中文。
3. 术语首次出现加注释；不机械重复套话。
4. 清晰 > 篇幅。写作风格不得削弱「事实」与「判断」的来源标注。

整周确无新内容时，出一期只有一条头条的「空周」简报：用一句人话总结本周通道情况，并附官方招生信息平台作为来源。
