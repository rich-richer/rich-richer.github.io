# 理财入门晚间课（finance-class）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：周六（试行出刊表）。窗口：**自上一期以来**（约一周，`coverage.start` = 上一期的 `coverage.end`）；市场部分用本周最后一个交易日的收盘数据。
- 读者：完全零基础的初学者。用大白话，分析师兼老师的语气，不煽动。
- 使用 AIHOT：否。

## 定位（硬性）

这只是**教育内容**：

- 绝不推荐买卖任何具体股票、基金或币种；绝不承诺收益。
- 不写灰色、违法或加杠杆的暴富玩法。区块链内容 = 讲机制 + 风险素养。
- 每期头条 `summary` 开头固定写：「本课仅供学习，不构成投资建议；投资有风险。」

## 条目安排（新闻版面改写）

原例程是一堂课，这里拆成带来源的条目：

| 原例程部分 | 条目 | priority | category |
| --- | --- | --- | --- |
| 一词一课（是什么 / 生活类比 / 为什么重要 / 常见误区） + 决策练习 + 今日作业 | 1 条 | `lead` | `一词一课` |
| 本周市场回顾：美股、中国股市（A 股 / 港股）、主要数字币（BTC / ETH 等）、区块链动态 | 各 1 条，共 4 条 | 最重要的 2 条为 `important`，其余 `normal` | `市场速览` |
| 新闻怎么读（1–2 条真实新闻，示范初学者该质疑什么） | 1–2 条 | `normal` | `新闻怎么读` |

### 一词一课（头条）

- 每周六一课，按以下顺序**按周轮换**，讲完一轮再从头开始；先看上一期讲的是哪一课，本期接着讲下一课（若本周有重大新闻更适合讲另一个概念，可替换并在报告中说明）：
  1. 应急金与现金流
  2. 通胀与购买力
  3. 股票 vs 公司所有权
  4. 指数与 ETF（可对比「股票 ETF vs 数字资产相关产品」的风险差异，不荐买）
  5. 风险、分散与「亏得起」
  6. 区块链基础一词（区块链、钱包、Gas、稳定币，每轮讲一个）
- 每期头条另加 2–4 句「本周主线回顾」。
- `summary` 结构：免责声明 → 是什么 → 生活类比 → 为什么重要 → 常见误区 → 决策练习（一道单选情景题 + 简短讲解，**不得**把真实股票代码或币种当作「正确买入答案」）→ 今日作业（一个很小的行动）。`summary` 可超过 400 字，但尽量精炼。
- `sources[0]`：权威的投资者教育资料（如中国证监会投资者保护、美国 SEC Investor.gov 等官方页面）。

### 市场速览

- 每块用大白话写「这一周发生了什么、初学者为什么该在意」，写进 `brief`。
- 价格 / 涨跌须经网页核实：写本周最后一个交易日的收盘数据和本周累计涨跌（注明起止收盘日）；数字币写北京时间出刊前的价格并注明时间。休市时注明并使用最近交易日。
- 区块链动态无经核实新闻时，不写该条，在报告中说明「本周无可靠区块链要闻」。
- **数字货币与区块链的新闻事实以双语每日新闻为准**（2026-09-27 改版）：主刊已报道的事件，本刊只用一句话交代事实，`sources[0]` 放主刊本站链接，篇幅用于解释概念、风险和对初学者的意义。美股、A 股等市场事实若主刊已写成完整报道，同样链接主刊。

### 新闻怎么读

- `brief`：新闻标题要点 + 初学者应该质疑的一个问题。必须附原新闻来源。

术语首次出现给出「中文（English）」。
