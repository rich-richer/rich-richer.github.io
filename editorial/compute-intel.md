# 电算协同每日情报（compute-intel）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：周一、周四（试行出刊表）。窗口：海外、中国取当日及最近 3 天；辽宁取最近 30 天内本刊未报道过的动向。
- 定位：一份**对外可见的产业情报**，展示对算力—电力产业的宏观判断力与专业度。点评站在产业与区域层面说话，**绝不出现任何内部策略、谈判打法、对合作方的算计或行动指令**。
- 网站版不署名（不出现筹备组名称），不写“请勿转载”类字样。
- 本刊保持产业专业性，专注电力、算力、数据中心、能源与产业政策（2026-09-27 改版）。涉及创业机会时，只在「意义」里点到为止，并链接全球创业机会期刊的相关条目（事件编号见 README 第 10 节），不在本刊展开商业分析。
- 使用 AIHOT：否。

## 主题范围

算力 / 数据中心 / 智算中心 · 电力市场与电价 · 算电协同 · 源网荷储一体化 · 绿电直连 · 虚拟电厂 / 新型储能 · 数据要素与数据资产入表 · 「人工智能+」政策 · AI 与 SaaS 产业动向（作为调剂，每期最多 1 条）。

## 条目安排

**每期 10 条：今日导读 1 + 海外 3 + 中国 3 + 辽宁 3**，与原「电算协同·每日情报」定时任务一致（海外 3 条以美国为主 + 中国 3 条 + 辽宁 3 条；样例见 2026-09-05 第 006 期 PDF）。辽宁确实找不到 3 条可靠动向时可以少写（至少 1 条），并在报告中说明；**不编造本地新闻**。

### 选题优先级（从高到低）

1. 当日 / 近日发布的国家级或州级**政策原文**（有文号、有链接的最有分量）。
2. 可类比到辽宁的**落地案例**（尤其县域、园区、签约金额、电价数字）。
3. 改变行业底层逻辑的**趋势与数据**（排队容量、投资额、电价涨幅、法案数量）。
4. 涉及**辽宁本地**的任何动向——只要有，必须优先入选。

### 硬性要求

- 每条必须有真实链接，且在检索或抓取中实际出现过；每条标注准确的发布日期（`publishedAt`）。
- 英文来源必须填 `originalTitle`（英文原标题），正文给出中文译述，并附**一句关键原文的中英对照**（写法见「版面映射」）。
- 数字（GW / MW / 亿元 / 元每度 / 百分比）尽量保留，它们是这份情报最有说服力的部分。每条挑出**最有冲击力的 3 个数字**（实在凑不出才写 2 个），单列为「关键数字」。
- 每条尽量附 2 个以上来源（官方原文 + 权威媒体），便于读者核对。
- 无法确认的信息宁可不写，或明确标注「此处待核实」；宁可少写一条，也不写来源不可靠的。

## 今日导读与今日一句话（头条）

对应原例程第 3 步「写导读与今日一句话」，放在版面最前面，作为本期 `lead`，`category` = `今日导读`：

- 标题：「今日导读：<本期主线，≤ 20 字>」。
- `summary` 按顺序写：
  1. 「今日主线：……」（≤ 25 字）；
  2. 「导读：」后接 **4 句**，每句一行意思，以①②③④编号，陈述当日最重要的 4 条事实与趋势，保留关键数字（样例：「得州 ERCOT 并网排队达 474 吉瓦、约九成为数据中心，州长下令暂停审批……」）。**只陈述事实与趋势，不写行动建议**；
  3. 「今日一句话：」收尾金句，串起当日各条，给出一个有锋芒的**产业判断**，可以落到辽宁的区位价值上，不写内部动作。
- `brief`：今日一句话的压缩版（≤ 80 字）。
- `sources`：本期 3 条重点条目的本站链接（格式 `https://rich-richer.github.io/p/compute-intel/?date=<日期>#<条目 id>`），读者点来源即可跳到对应条目。

## 「对我们的意义」写作口径（最需要拿捏分寸）

**要写的**：

- **产业层面的宏观判断**：这条新闻揭示了什么趋势、规律或结构性变化。
- **区域层面的推论**：这一趋势对「电力富余、消纳有空间、工业底盘完整」的区域意味着什么。
- **辽宁的比较优势**（可以正面陈述）：电网基础扎实、东北电网调节能力强、新能源装机持续增长而本地消纳仍有余量、传统重工业负荷退坡释放存量容量、沈阳至京津网络时延具备竞争力、完整工业体系与省会城市的人才配套、大量高耗能存量用电客户。

**绝对不能写的**：

- 任何“建议我们本周做 X”“把这条用在与某方谈判时”“这是最有力的一张牌”类**行动指令或谈判打法**。
- 任何涉及我方与合作方（包括大云中联）之间的关系、诉求、代理权、授权、分成、话术的内容。
- 任何对合作方、政府部门的评价、算计或心理揣测。
- 任何内部材料的修改建议；自我吹嘘或贬低他人。

**篇幅与语气**：每条 120–190 字，1–3 句。首句点出核心判断，后续展开推论并落到区域禀赋。语气笃定、克制、有产业视野，像研究机构的观点，不像销售话术。第三人称产业观察视角，不写“我们应该……”。

参考范例（德州暂停数据中心并网）：

> 电力正在取代芯片，成为算力扩张的真实天花板。连全球最市场化、审批最快的电网都已不堪重负，说明这是一项全球性的硬约束，而非局部现象。这一约束越紧，电力供应有余量的区域战略价值就越高。辽宁电网基础扎实、东北电网调节能力强、新能源装机持续增长而本地消纳仍有空间——「有电可用、且有电待消纳」的区域，在算力产业的下一轮布局中稀缺性只会上升。

## 版面映射

卡片上头条显示 `summary`、其余条目显示 `brief`，文字按版面截断；读者点「展开全文」可看到完整 `summary`（见 README 第 4 节与 `docs/LOCAL_CHANGES.md` 第 2 项）。深度对齐原例程（正文约 300 字 + 点评约 150–190 字），因此本刊 `summary` 上限放宽到 **650 字**（出刊脚本已单独放宽，其他长度规则不变）。

- `brief`（≤ 80 字）：一句事实 + 「意义：」后接核心判断的压缩版（即点评首句的精简）。
- `summary`（400–650 字）按以下顺序写：
  1. **事实正文**（约 250–320 字）：谁、何时、发布了什么，文号、金额、容量、电价等数字保留；英文来源的关键原话在此处给出中文译文（加引号）。
  2. **关键数字**：另起一句「关键数字：474 吉瓦（并网排队）｜5 倍以上（相当于历史峰值负荷）｜12 月 10 日（核查报告目标日期）」，2–3 个。
  3. **「意义：」完整点评**（120–190 字，口径见上）。
  4. 英文来源：末尾另起「EN: 」写**一句关键原文**（页面会单独显示成英文行）。中国来源不写 EN。
- `selectionReason`：写明入选依据（对应上面的选题优先级第几条）。
- **头条**（`lead`）：今日导读卡（见上节），`summary` 以「今日主线：」开头。
- `important`：当天对区域判断最重要的 2 条新闻；其余 `normal`，按 海外 → 中国 → 辽宁 排列。
- 网站公开，点评在正文中统一以「意义：」引出（即原「对我们的意义」），不署筹备组名称。

## 语气与红线

- 中文简体，简洁笃定，不用「值得注意的是」「综上所述」这类填充语；不用 emoji。
- 不吹捧、不贬低任何企业，保持平视的专业口吻。
- 涉及资质、政策额度、承诺的表述一律保守，加「须一事一议核实」。
