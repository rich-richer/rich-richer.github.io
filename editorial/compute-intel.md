# 电算协同每日情报（compute-intel）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 建议频率：工作日。窗口：过去约 24 小时。
- 视角：AIggy 与大云中联的业务感知（按用户决定公开）。
- 使用 AIHOT：否。

## 业务视角

云计算、电算协同、政府 / 企业数字化、数据中心、信创（Xinchuang）、辽宁 / 东北地区数字经济，以及相邻的 IT 服务机会。企业 / 政务区块链或联盟链仅在与数字化采购或政策相关时才写，不写散户加密货币交易炒作。

## 条目安排

| category | 内容 | 条数 |
| --- | --- | --- |
| `海外` | 以美国为主的可核实新闻 | 最多 3 |
| `中国` | 全国层面政策、项目、企业动态 | 最多 3 |
| `辽宁` | 省 / 市 / 地方产业政策、项目、人才、园区 | 最多 3 |

- 辽宁没有可靠消息时如实说明（写进报告），**不要编造本地新闻**。
- 原例程的「导读」和「今日一句话总结」并入头条：`lead` 的 `summary` 开头用一句话概括当天全局，写成「今日主线：……」，不超过 25 字，给后面的「意义」留出位置。

## 版面映射

- 每条都要有「对我们的意义」：非头条写进 `brief` 后半句（「意义：……」），头条写进 `summary`；`selectionReason` 完整保留。
- `lead` 1 条、`important` 2 条，从三个分类中选对业务影响最大的。
- 中文；英文来源填 `originalTitle`。术语首次出现写作「中文（English）」。
