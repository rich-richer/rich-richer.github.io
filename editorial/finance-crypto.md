# 金融与加密简报（finance-crypto）

先读 [`README.md`](./README.md)。本手册只写这份刊物的特有规则。

- 创刊：2026-09-30，由三部分合并而成：原工作日早晨简报的「美股 ETF」、原理财入门晚间课的全部内容（一词一课、市场速览、新闻怎么读）、原双语每日新闻的「数字货币与区块链」板块。两份旧刊停刊存档，旧期仍可阅读。
- 建议频率：周一、周四（试行出刊表）。窗口：**自上一期以来**（约 3–4 天，`coverage.start` = 上一期的 `coverage.end`）；首期取过去 3 天。行情用最近一个已收盘交易日的数据，并给出自上一期以来的累计涨跌（注明起止收盘日）。
- 读者：AIggy 与零基础读者。先讲「发生了什么」，再讲「读懂它需要知道什么」。分析师兼老师的语气，大白话，不煽动。
- 使用 AIHOT：否。

## 定位（硬性）

- 这是**资讯与教育内容**：绝不推荐买卖任何具体股票、基金或币种，绝不承诺收益，不写喊单、目标价、仓位建议。
- 不写灰色、违法、加杠杆或来路不明的暴富玩法；数字货币与区块链只从合法合规视角写（监管、ETF 与机构资金、合规产品、托管、受监管稳定币、数字人民币、重大安全事件）。
- 头条 `summary` 开头固定写：「本刊仅供学习，不构成投资建议；投资有风险。」

### 一词一课

- 按以下顺序**轮换**，讲完一轮从头开始；先看上一期（含停刊的理财入门晚间课旧期）讲到哪一课，本期接着讲下一课。本期新闻恰好更适合讲另一个概念时可以替换，并在报告中说明。
  1. 应急金与现金流
  2. 通胀与购买力
  3. 利率、债券与央行
  4. 股票与公司所有权
  5. 指数与 ETF
  6. 风险、分散与「亏得起」
  7. 汇率与跨境资产
  8. 区块链与比特币
  9. 钱包、私钥与托管安全
  10. 稳定币与数字人民币
- `summary` 结构：是什么 → 生活类比 → 为什么重要（联系本期新闻）→ 常见误区 → 小练习（一道情景单选题 + 简短讲解，**不得**把真实股票代码或币种当作「正确买入答案」）。
- `sources[0]`：权威的投资者教育资料（如中国证监会投资者保护、美国 SEC Investor.gov、中国人民银行等官方页面）。

### 新闻怎么读

- `brief`：新闻要点 + 初学者应该追问的一个问题。
- `summary`：这条新闻说了什么 → 哪些是事实、哪些是观点或预测 → 该追问的 2–3 个问题（数据口径、谁在说、利益相关）→ 一句话结论。必须附原新闻来源。

## 版面映射

- `lead`：本期市场主线，从 `市场速览`、`数字货币与区块链`、`金融要闻` 中选最重要的一条。`summary` 以免责声明开头，接「本期主线：……」一两句概括全局，再写事实与数字。
- `important`：其余最重要的 2 条。
- 其余为 `normal`，按 市场速览 → 数字货币与区块链 → 金融要闻 → 一词一课 → 新闻怎么读 → 财经日历 排列。
- 英文来源填 `originalTitle`，正文给中文译述；专业术语首次出现写作「中文（English）」。

## 核查

- 所有数字、日期、价格必须联网核实，不凭记忆；来源之间有矛盾的用「⚠️」标出并写明各自出处。
- 只收录能从检索结果验证的信息，个别细节无法核实时标注「⚠️ 待核实」，绝不编造新闻或链接。
