# 出刊说明书

适用于 https://rich-richer.github.io/ 的 10 份刊物。最后更新：2026 年 9 月 26 日。

在线版（带复制按钮）：https://claude.ai/artifact/BfXNCKcpCDJextBEiG3Be5

> **只记一句话就够了**：在 daily-news-app 项目里说「**出刊并发布 今天的**」。
>
> 说完就可以离开。我会按当天是星期几挑出该出的刊物，全自动检索、核实、写稿、发布，最后用三项报告告诉你结果。「出刊」和「出刊并发布」效果一样，都会直接上线。

## 一、出刊时间表（试行）

每周出 3 次，每次说一句话。其他日子不用管。

| 出刊日 | 时间 | 出哪几份 | 份数 |
| --- | --- | --- | --- |
| 周一 | 早上 7 点前后 | 双语每日新闻、工作日早晨简报、电算协同每日情报、自媒体选题简报、AI 架构周报 | 5 份，收进上周五到周日的消息 |
| 周四 | 早上 7 点前后 | 双语每日新闻、工作日早晨简报、电算协同每日情报、自媒体选题简报、人物动态追踪 | 5 份，收进周一到周三的消息 |
| 周六 | 上午 | 理财入门晚间课、赛道与创业周报、AI 安全公开动态、升学就业周报 | 4 份，收全一整周，适合周末细读 |

**为什么这样排**：美股在北京时间凌晨收盘，早上出能写已收盘的数据。周一和周四把一周切成两半，新闻不漏；电算情报看「最近 3 天」，正好对得上。周刊放在最适合读它的那天。

- 耗时参考：每份约 15–30 分钟（估计），5 份约 1.5–2 小时，期间你不用在场。早上任何时候说都可以；想 8 点半前看到，就 7 点前说。
- 试行说明：双语新闻、早晨简报目前仍按 24 小时、48 小时取新闻，隔几天出一期时中间的新闻会漏一部分。觉得漏得多，就说「把窗口改成自上一期以来」。

## 二、在电脑上出刊

1. 打开 Mac 上的 Claude 应用，切到 **Code** 标签。
2. 点**新建会话**，文件夹选 `/Users/richricher/Claude-Projects/daily-news-app`。每次出刊都新开一个会话，省额度，也更快。
3. 在输入框里发送：`出刊并发布 今天的`
4. 可以离开。中途弹出的「允许运行命令、打开网页」之类的确认，是 Claude 应用自己的权限确认，点允许即可。
5. 收到完成通知后，看最后的三项报告：出了哪几份（带网址）、没收的内容、需要你处理的事。

## 三、在手机上出刊

出刊始终在你的 Mac 上运行，手机只负责派活和查看。所以 **Mac 要开着、Claude 应用要运行、盖子不要合上**。

### 方式一（推荐）：用 Dispatch 让 Mac 新开会话

1. 打开手机上的 Claude 应用，进入 **Cowork** 标签，找到 **Dispatch** 对话。
2. 发送下面这段话，最好原样复制，写明项目文件夹，避免选错：

   ```text
   在 Claude Code 里打开 /Users/richricher/Claude-Projects/daily-news-app 项目，新开一个会话，执行：出刊并发布 今天的
   ```

3. Mac 上会新开一个带 Dispatch 标记的 Code 会话，开始全自动出刊。
4. 完成或需要你批准时，手机会收到推送。点 **Code** 标签，找带电脑图标的会话，查看进度和最后的报告。

Dispatch 需要 Pro 或 Max 套餐。Cowork 标签里找不到 Dispatch 时，用方式二。

### 方式二（备用）：远程控制已经开着的会话

1. 出门前，在 Mac 的 Code 标签新建一个会话，文件夹选 `daily-news-app`。它会自动连上远程控制（设置里已开启）。
2. 在手机 Claude 应用里点 **Code**，找到带电脑图标的这个会话，发送「出刊并发布 今天的」。

手机不能从零新建本机会话，所以方式二要先在 Mac 上开好会话。

## 五、常用说法

| 你说 | 效果 |
| --- | --- |
| 出刊并发布 今天的 | 按上面的时间表，出当天该出的几份（日常用这句） |
| 出刊并发布 全部 | 10 份全部出，适合隔了很久没出、想一次补齐 |

| 把某刊改成…… | 改刊物的内容规则、条数或样式；改页面代码前我会先问你 |

## 六、出刊前检查

- [ ] Mac 开着，Claude 应用在运行（不要退出应用）。
- [ ] 笔记本盖子打开（「保持唤醒」只防闲置休眠，合盖照样会睡）。
- [ ] 在 `daily-news-app` 项目里新开的会话，不是别的文件夹。
- [ ] 手机上打开了 Claude 的通知（用手机出刊时）。
- [ ] 法定节假日和长假期间，理财课和电算情报可以停，节后第一天再出。

## 七、遇到问题

- **网站上还是旧内容或旧样式**：浏览器会把网页缓存最多 10 分钟。按 `Command + Shift + R` 强制刷新；手机上稍等几分钟再打开。
- **报告里写着「需要你处理的事」**：照报告里的说明做，或直接回复我怎么处理。出刊中途我不会问你问题，只有测试、构建或推送失败这类我解决不了的故障才会停下。
- **某份刊物当天没出**：通常是网络检索失败或没有可靠新闻。我不会拿旧闻或凭记忆凑数，报告里会写明原因。可以晚些再单独出那一份。
- **手机上派了活，Mac 没反应**：检查 Mac 是否休眠或合盖、Claude 应用是否在运行、手机和 Mac 是否登录同一个账号。都正常的话，改用方式二。
- **想少被权限确认打扰**：在 Mac 的「设置 → Claude Code」里把默认权限模式改得宽松一些，比如「自动（auto）」。这是你的安全设置，由你决定。
